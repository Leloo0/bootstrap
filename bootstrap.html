Documentação do Projeto

Entenda os conceitos do Bootstrap utilizados na construção do site Sabor & Arte.

O que é Bootstrap?

O Bootstrap é o framework front-end em HTML, CSS e JavaScript mais popular do mundo. Ele fornece componentes pré-estilizados e utilitários que aceleram a criação de interfaces modernas.

Para que serve?

Ele resolve o problema de padronização entre navegadores e elimina a necessidade de escrever CSS do zero para layouts responsivos, oferecendo acessibilidade, alinhamento automático e elementos prontos.

Sistema de Grid

O sistema de grid do Bootstrap usa uma estrutura de 12 colunas flexíveis baseada em Flexbox. As principais classes utilizadas neste projeto foram:

  • .container: Agrupa e centraliza o conteúdo da página com limites de largura.
  • .row: Envolvente horizontal que organiza e alinha as colunas.
  • .col: Cria colunas de largura automática ou proporcional.
  • .col-md-*: Aplica o tamanho de coluna a partir de telas médias (≥768px).
  • .col-lg-*: Aplica o tamanho de coluna a partir de telas grandes (≥992px).
Exemplo prático de código usado nos Cards: 
<div class="col-12 col-md-6 col-lg-4">
    <!-- O card ocupa 12 colunas no celular, 6 no tablet e 4 no desktop -->
</div>

Responsividade

Através de Media Queries internas e Breakpoints do Bootstrap, as telas se reorganizam automaticamente para melhor usabilidade:

Celulares
1 coluna por linha
Tablets
2 colunas por linha
Notebooks
3 colunas por linha
Monitores
Grade completa

5 Componentes Utilizados no Projeto

Componente Onde foi aplicado? Função no Projeto
1. Navbar Topo de todas as páginas Fornece navegação responsiva rápida com menu retrátil em telas menores.
2. Card Páginas Início e Cardápio Organiza visualmente as fotos, descrições e preços dos pratos.
3. Alert Página Início (`index.html`) Exibe o aviso interativo de promoção de inauguração com botão de fechar.
4. Button (`btn`) Todas as páginas Padroniza botões de ação e reserva (`btn-danger`, `btn-warning`, `btn-outline-light`).
5. Badge Cards dos pratos Destaca os preços dos pratos no cardápio de forma compacta.
