## 📖 Descrição do Projeto
O **Sabor & Arte** é um site institucional e interativo para um restaurante fictício. O projeto foi desenvolvido como desafio prático para a aplicação dos conceitos do framework **Bootstrap 5**, utilizando componentes padronizados, responsividade completa e sistema de grid.

---

## 🛠️ Tecnologias e Ferramentas
- **HTML5**: Estruturação semântica das páginas.
- **CSS3**: Personalizações adicionais (`css/style.css`).
- **Bootstrap 5 (via CDN)**: Framework principal para responsividade e estilos.
- **Bootstrap Icons**: Ícones nos botões e menus.
- **Vercel**: Hospedagem da aplicação.
